# ASM-F2 Size Qualification on COM4 — 2026-09-15

ASM-F2 `00.0915(2243)` is installed in Bank-3 sectors 8-B. It occupies
15,235 bytes, ends at `$BB83` exclusive, and leaves 1,149 bytes below HIMON.
The saving is 530 bytes, with unchanged UDATA layout and published ABI.
HIMON remains `00.0915(2233)` and STR8-N remains 1.34. Bank 0-2 carriers
were not exercised or requalified in this run.

The [size report](../ASM/SIZE_REDUCTION_2026-09-15.md) describes the source
changes and exhaustive host checks. The append-only
[serial capture](ASMF2_SIZE_2026-09-15.jsonl) records the actual commands,
source, responses, transfers, and readbacks as timestamped TX/RX hex.

## Installation and recovery

The first `I / 3 / 8-B` transfer used the generated component with S9 `$8000`.
STR8 returned `FAIL` after S9, without offering COMMIT: the existing immutable
Bank-3 entry is `$C000`. The host harness timed out waiting for COMMIT because
it did not recognize the already captured FAIL response. This was an
installation preparation error, not an ASM execution failure.

The interrupted transaction required the documented complete writable-bank
recovery range, 8-E. A dense recovery stream combined the qualified ASM image
with the exact previously read HIMON C-E bytes, including its original stamp
and padding. Every recovery byte was checked against those inputs before
transfer. S9 was `$C000`. `I / 3 / 8-E`, COMMIT Y returned `OK`; a full-bank
readback proved the new ASM and preserved surrounding contents.

The Makefile now generates the ASM-only component with S9 `$FFFF` to retain
the existing HIMON entry. Its generator accepts this no-change value for the
8-B component, and `board-s19-check` checks exact range, length, and S9.
All nine canonical payload comparisons pass; a checksummed negative fixture
with the old S9 `$8000` is rejected by the new check. Older packaged releases
have not been republished and remain unsuitable for this partial update.

The corrected canonical component was then installed using `I / 3 / 8-B`.
STR8 offered COMMIT, returned `OK`, and cold-entered HIMON. Another full-bank
readback matched every byte, with only the expected installer journal advance
relative to the recovered bank. This is the final installed image.

## Board checks

The complete corrected test run passed after the final 8-B install:

- Nine rejected lines kept PC at `$2001`; successful surrounding DB lines
  yielded exactly `A5 5A`, two symbols, zero fixups, and zero references.
  Cases covered range, unsupported expression operators, immediate size,
  trailing comma, STA immediate, duplicate symbol, and protected ORG.
- All 217 legal instruction forms yielded 464 bytes matching an independent
  host opcode oracle, including all bit-number variants. WAI and STP were
  assembled and inspected, not executed.
- NEW cleared a sticky source error; the next clean session emitted
  `A9 42 60` and exited without EXEC ERR.
- The existing 189-byte opcode runtime card matched exactly, then ran both
  directly and through AP relocation. Both returned A=`AC`, carry set,
  and wrote `$7904=AC`.
- SEAL and RELOCATE moved the ten-byte workflow body from `$2000` to `$3000`.
  PACKAGE with a wrong identity left its 64-byte destination guard unchanged.
  Warm `ASM SEAL`, PACKAGE, and LOAD to `$4000` succeeded; exact relocated
  bytes and execution (`A=C3`, carry set, `$7905=C3`) passed.
- A 240-byte AP-v2 package with eight exports, sparse symbol slots, varied
  PACK40 name lengths, three resident imports, and three imported calls
  matched the host package exactly. LOAD bound all imports and the entry
  returned A=`AC`, carry set, writing `$7907=AC`.
- Newly assembled `BRK $41` trapped at PC `$2002`; N stepped LDA and STA;
  X reached `BRK $42` at PC `$2009`, with `$7908=42`; the final X resumed RTS
  and returned to the HIMON prompt.

Two initial harness assertions were corrected without changing firmware:
short HIMON dumps have a different row shape, so the reader now requests
aligned 16-byte rows; X resume returns silently after RTS, without the RET
message printed by an uninterrupted G. The final complete run passed.

and the default warm entry to HIMON `00.0915(2233)`. `ASM NEW` displayed

RTS`; G returned A=`AC`, carry set, and memory `$7909` read `AC`.
